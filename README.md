# 📚 Matemáticas.top

![Matemáticas.top Banner](https://via.placeholder.com/800x300/6366f1/ffffff?text=Matem%C3%A1ticas.top)

**Plataforma educativa online para estudiantes de ESO y Bachillerato en España**

> Entiende, aprende y aprueba matemáticas con nuestro método innovador

## 🎯 Sobre el Proyecto

Matemáticas.top es una plataforma educativa diseñada específicamente para estudiantes españoles de 12 a 18 años que buscan mejorar sus habilidades matemáticas. Ofrecemos:

- **Clases particulares personalizadas** para ESO y Bachillerato
- **Recursos educativos gratuitos** incluyendo calculadoras y formularios
- **Videos explicativos** en YouTube con metodología clara y didáctica
- **Preparación especializada** para la EVAU/Selectividad

## 🚀 Características

### ✨ Diseño Moderno y Responsive
- Interfaz moderna y atractiva para estudiantes
- Completamente responsive (móvil, tablet, escritorio)
- Animaciones suaves y experiencia de usuario optimizada
- Modo de alto contraste para accesibilidad

### 🎓 Contenido Educativo
- **ESO (12-16 años)**: Álgebra básica, geometría, funciones, estadística
- **Bachillerato (16-18 años)**: Análisis, cálculo, trigonometría, integrales
- **Selectividad**: Preparación intensiva para la EVAU

### 🛠️ Herramientas Interactivas
- Calculadora científica integrada
- Graficador de funciones (próximamente)
- Banco de ejercicios resueltos
- Formularios PDF descargables
